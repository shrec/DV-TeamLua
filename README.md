# DevEmu Lua Wiki

Public documentation for the DevEmu Lua scripting API, covering both client-side and server-side development.

This repository is consumed as a Git submodule by the (private) DevEmu server project, but the wiki itself is published publicly so that scripters can read it without needing access to the engine source.

## Layout

GitHub wiki convention — flat Markdown files, hyphenated names:

- `Home.md` — landing page
- `_Sidebar.md` — navigation
- `_Footer.md` — footer shown on every page
- `<Topic>.md` — content pages

## Contributing

Open a pull request against this repository. Each page is a single Markdown file. Cross-links use the page name without the `.md` extension, e.g. `[Player Structure](Player-Structure)`.
